# Название проекта: **ikanamRAG**

---
Проект состоит из нескольких этапов:

1) Сборка датасета
2) Чистка и предобработка данных
3) Деление на чанки и структурирование
4) Визуализация на Streamlit
5) Поиск зависимостей


Для запуска каждого этапа следует скачать библиотеки, которые требуются и получить токен VK_API
---

# 1. Сборка датасета
---
Запуск проекта начинается с 1 этапа, который находится в одноимённой папке. Для запуска нужно получить свой токен. По поводу токена у есть подозрение, что .gitignore может не заработать без файла
.env с токеном, который не прикрепили. Поэтому на всякий случай, чтобы не заливать токен в GitHub, его отправили/отправят на почту, чтобы могли им воспользоваться, если код не будет работать.

P.S. Если что парсинг комментариев может занять некоторое время, у меня вышло около 15 минут. 


# 2. Чистка и предобработка данных
---
После 1 этапа берём файл со спарсенным датасетом и запускаем 2 этап, где должны получить обновлённый датасет с очищенными данными

# 3. Деление на чанки и структурирование
---
Далее запускается 3 этап, куда следует закинуть файл, полученный во втором этапе и после него должны получится три файла, которые пригодятся в следующем этапе

# 4. Визуализация на Streamlit
---
Этот этап отличается тем, что его следует запускать через терминал:
Следует сначала перейти в папку, где находится код и файлы, полученные на третьем этапе, а потом через "streamlit run vizualization.py" запустить код, который переведёт в браузер и откроет веб-приложение с визуализацией

# 5. Поиск зависимостей
---
Для поиска зависимостей требуется файл, полученный во втором этапе
